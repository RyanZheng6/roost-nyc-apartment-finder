Roost uses API.SH's free monthly StreetEasy API credits, with a hard local quota. Add APISH_KEY to .env, restart and click Check for new listings. Optional: connect the mailbox receiving your own StreetEasy saved-search notification emails via read-only IMAP. Email alert timing is set by StreetEasy, not Roost.
