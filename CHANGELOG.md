# Changelog

## v1.0.0 — Initial GitHub edition

- NYC rental listings dashboard with StreetEasy provider connector.
- Search filters, saved searches, favorites, and email alerts.
- Transit routing with persistent Google API budget limits.
- Leaflet map with listing markers.
- Local SQLite storage and Windows installation/update scripts.

This is the first version tracked in GitHub; previous ZIP iterations are not represented as historical Git commits.

## v1.1.0 — Windows launcher

- Added GitHub Actions Windows executable build and one-click launcher.
- Moved user data to Downloads/RoostData, with first-run legacy copying.
- Preserves saved searches, favorites, email settings, and API counters across binary updates.
